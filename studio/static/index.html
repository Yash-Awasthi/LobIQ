LobIQ studio

Build the tools first

The studio drives the C++ tools; until they are built it can only browse reports already on disk. The tools need Linux (or a Linux container). Pick one:

  1. No install: open the repository in GitHub Codespaces (the badge in the README). The container builds everything; then run lobiq demo && lobiq studio and open the forwarded port 8000.
  2. Windows: wsl --install -d Ubuntu, restart, then inside Ubuntu: sudo apt install g++ cmake ninja-build git curl zip unzip pkg-config libssl-dev python3, clone the repo, set VCPKG_ROOT to a vcpkg checkout, cmake --preset release && cmake --build build/release, export PATH="$PWD/scripts:$PATH", lobiq studio. Windows' browser reaches it at http://127.0.0.1:8000/.
  3. Docker or Podman: docker run --rm -p 8000:8000 ghcr.io/yash-awasthi/lobiq lobiq studio --bind 0.0.0.0
  4. Linux: the same cmake commands, or a release archive (bin/lobiq studio).

What you can do here

  • Backtest: a strategy on a past Nasdaq day, order by order, with your orders waiting in the real queues.
  • Paper replay: a quote model on a recorded live prediction-market session, through risk checks, an order manager and a simulated venue with latency and fees.
  • Live paper: the same on the live feed, now; no order is ever sent.
  • Leaderboard: every backtest ranked by risk-adjusted return, with the deflated Sharpe ratio.
  • Order book and Analysis: any book at any second; surveillance, execution quality, studies.

Quick start

No data yet? The demos need none: a synthetic Nasdaq session through two strategies and a 10-run sweep, and paper execution on the bundled 20-minute live recording. Results land in the leaderboard.

    Markov chain of the order book
    
      
    The top of the book is in one of a few states: the spread (1, 2, or 3+ ticks) and the bid's
        share of the best-level size. The chain counts how the book moves between states and, from each state,
        whether the next price move went up or down. Counted from 09:35 to 12:45, it then predicts every move of
        the afternoon; the hit rate is scored against always guessing the more frequent direction.

    Four classic models of how prices form and how traders should act, in closed form. Change any input
    and the charts follow. Formulas and sources: docs/METHODS.md, "Models".
    
  
    
    
    
      
    Kyle (1985): an insider, noise traders and a market maker
    
      
    One insider knows the asset's value; noise traders trade at random; the market maker sees only total
        order flow. In the Nash equilibrium the insider trades β(v − p₀) and the price moves λ per share of flow.
    
      
    
        
    
      
    
    
    
    
    
      
    Glosten–Milgrom (1985): why spreads exist
    
      
    The value is high or low. A share μ of traders know which; the rest trade at random. Competing market
        makers quote where they break even, so the spread pays for trading against the informed. Below: quotes as the
        market learns, trade by trade, when the value is high.
    
      
    
        
        
        
    
      
    
    
    
    
    
      
    Almgren–Chriss (2000): selling a large order
    
      
    Selling fast moves the price against you; selling slowly leaves you exposed to the market. Risk aversion
        λ picks the trade-off: the schedule bends toward selling early, and the frontier shows every best trade-off.
    
      
    
        
        
        
        
        
        
    
      
    
    
    
    
    
      
    Avellaneda–Stoikov (2008): where a market maker quotes
    
      
    A market maker holding inventory shifts both quotes against it and widens them with volatility and time
        left. The avellaneda_stoikov backtest strategy uses these quotes (with the GLFT bounded-inventory form).
