LobIQ studio

Build the tools first

The studio drives the C++ tools; until they are built it can only browse reports already on disk. The tools need Linux (or a Linux container). Pick one:

  1. No install: open the repository in GitHub Codespaces (the badge in the README). The container builds everything; then run hft demo && hft studio and open the forwarded port 8000.
  2. Windows: wsl --install -d Ubuntu, restart, then inside Ubuntu: sudo apt install g++ cmake ninja-build git curl zip unzip pkg-config libssl-dev python3, clone the repo, set VCPKG_ROOT to a vcpkg checkout, cmake --preset release && cmake --build build/release, export PATH="$PWD/scripts:$PATH", hft studio. Windows' browser reaches it at http://127.0.0.1:8000/.
  3. Docker or Podman: docker run --rm -p 8000:8000 ghcr.io/yash-awasthi/lobiq hft studio --bind 0.0.0.0
  4. Linux: the same cmake commands, or a release archive (bin/hft studio).

What you can do here

  • Backtest: a strategy on a past Nasdaq day, order by order, with your orders waiting in the real queues.
  • Paper replay: a quote model on a recorded live prediction-market session, through risk checks, an order manager and a simulated venue with latency and fees.
  • Live paper: the same on the live feed, now; no order is ever sent.
  • Leaderboard: every backtest ranked by risk-adjusted return, with the deflated Sharpe ratio.
  • Order book and Analysis: any book at any second; surveillance, execution quality, studies.

Quick start

No data yet? The demos need none: a synthetic Nasdaq session through two strategies and a 10-run sweep, and paper execution on the bundled 20-minute live recording. Results land in the leaderboard.
