hft: demo reports

Generated by scripts/demo/all.sh at commit @COMMIT@. Every number is checked against a fixed value when the demos run.

Paper execution on a real recording

20 minutes of Polymarket's live order-book stream, replayed through the market makers and the arbitrage executor, pre-trade risk, the order manager and a simulated venue. PnL, fills, latency per stage and every arbitrage window the executor refused, with the reason.

 Backtest: join the best bid and ask

A synthetic Nasdaq session (queue-reactive order flow) through the event-driven backtester: orders wait in the real queues, with latency and fees.

 Backtest: the example strategy

The strategy from the writing-a-strategy guide: joins the best but steps back when the top-of-book size imbalance points against a side.

 Parameter sweep

The example strategy over 10 parameter combinations, run in parallel: ranked table with a link to each run's report and the PnL curves side by side.
